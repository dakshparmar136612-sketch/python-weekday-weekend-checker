# Python Weekday Weekend Checker

A simple Python program that uses the `match-case` statement to determine whether a given day is a weekday or a weekend.

## Features

- Accepts a day of the week as input.
- Uses Python's `match-case` statement.
- Identifies weekdays and weekends.
- Handles invalid input.

## Requirements

- Python 3.10 or later

## How to Run

```bash
python weekday_checker.py
```

## Example

```
Enter a day of the week: monday
It's a weekday
```

```
Enter a day of the week: sunday
It's the weekend
```

```
Enter a day of the week: holiday
That's not a valid day
```

## Concepts Used

- Python
- `input()`
- `lower()`
- `match-case`
- Pattern Matching
